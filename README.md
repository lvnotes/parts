# Тести: знаходження числа за його дробом (4 клас)

Інтерактивна сторінка з 5 тестовими завданнями на тему «Знаходження числа за його дробом». Показує, чи відповідь правильна, і розв’язання кожного завдання.

##Посилання на сторінку:
https://lvnotes.github.io/parts/

## Як це працює

На сторінці 5 завдань. У кожному 6 варіантів відповіді (А–Е). Після вибору відповіді завдання блокується:

- правильний варіант підсвічується зеленим із позначкою ✓;
- обраний неправильний варіант підсвічується червоним із позначкою ✗, а під завданням показується правильна відповідь;
- під завданням з’являється розв’язання, наприклад: 54 : 3 = 18 (це 1/8), 18 · 8 = 144 км;
- угорі сторінки лічильник «Правильно: N з 5» і п’ять індикаторів (зелений — правильно, червоний — помилка);
- після відповіді на всі завдання показується підсумок і кнопка «Пройти ще раз».

## Завдання і генерація даних

Умови завдань незмінні, а числа генеруються випадково щоразу, коли відкривається сторінка або натискається «Пройти ще раз». Для кожного завдання випадково обираються знаменник d, чисельник n і «одна частка» u. Тоді:

- відома частина = n · u;
- шукане число = d · u (завжди ціле).

| № | Тип | Діапазони |
|-|--|------|
| 1 | «Знайти число, 1/d якого становить …» | d = 3–9, n = 1, u = 3–25 |
| 2 | «Знайти число, n/d якого становить …» | d = 3–9, n = 2–4 (менше за d`), `u = 3–30 |
| 3 | Довжина маршруту туристів (км) | d = 6–10, n = 2…`d`−1, u = 2–6 |
| 4 | Гроші Олі (грн) | d = 5 або 10; при d = 5: n = 2–4, u = 20–120; при d = 10: n = 2–7, u = 10–50 (кратні 10) |
| 5 | Кількість саджанців | d = 6–8, n = d`−3…`d`−1, `u = 4–12 |

Завдання 3–5 — текстові задачі. Контекст і формулювання не змінюються, змінюються лише числа. Слово «саджанець» узгоджується з числом (1 саджанець, 22 саджанці, 25 саджанців).

## Варіанти відповіді

Правильна відповідь стоїть на випадковій позиції серед шести. П’ять неправильних варіантів вибираються випадково з типових помилок:

- відому частину взяли як відповідь (`n · u`);
- взяли одну частку (`u`);
- помножили частину на знаменник без ділення (`n · u · d`);
- помилилися на одну частку (`d · u ± u`);
- додали або відняли чисельник чи знаменник (`частина + d`, `d · u ± n`).

Усі варіанти додатні й різні. Якщо унікальних помилок бракує, список доповнюється значеннями d · u + k · u.
